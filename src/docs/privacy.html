It is run by a student developer, aitji (Suriya Inchoo), who is the data controller for this policy. Covered services: the URL shortener, file sharing and QR code generator at go.thatako.net, and the free subdomains at id.thatako.net. ข้อมูลที่เราเก็บ · Information we collect

ลิงก์และไฟล์ · Links and files

เมื่อสร้างลิงก์ เราเก็บ slug ปลายทาง วันที่สร้าง และ secret key ที่สุ่มจากเบราว์เซอร์ของคุณ ในฐานข้อมูล (Cloudflare KV) secret key เก็บแบบข้อความธรรมดา ไม่ได้เข้ารหัสแฮช เพื่อให้เราช่วยกู้ลิงก์ให้ครูที่ทำ key หายได้ ซึ่งหมายความว่าผู้ดูแลระบบเห็น key ได้ เราไม่ขอชื่อ อีเมล หรือรหัสผ่าน เราไม่บันทึกว่าใครคลิกลิงก์ ระบบอาจแคชลิงก์ที่ถูกใช้บ่อยเพื่อให้เปลี่ยนเส้นทางเร็ว แคชนี้ไม่มีข้อมูลผู้เข้าชม

When you create a link we store the slug, destination, creation date and a random secret key generated in your browser, in our database (Cloudflare KV). The secret key is stored as plain text, not hashed, so we can help teachers recover links if they lose a key. This means the operator can see keys. We do not ask for your name, email or password. We do not record who clicks a link. The system may cache frequently used links to redirect quickly; this cache holds no visitor information.

ไฟล์บนเซิร์ฟเวอร์ · Files on our server

หากเลือกเซิร์ฟเวอร์ เราเก็บเนื้อหาไฟล์ ชื่อ ขนาด และ MIME type ใน Cloudflare R2 (ภูมิภาคกำหนดอัตโนมัติ) จนถึงวันหมดอายุที่เลือก (7–90 วัน) แล้วลบอัตโนมัติ

If you choose server storage, we keep the file contents, name, size and MIME type in Cloudflare R2 (region assigned automatically) until your chosen expiry (7 to 90 days), then delete them automatically.

ไฟล์บน Google Drive · Files on your Google Drive

เนื้อหาไฟล์ส่งจากเบราว์เซอร์ไปยัง Drive ของคุณโดยตรง ไม่ผ่านเซิร์ฟเวอร์ของเรา เราเก็บเพียง Drive file ID ชื่อ ขนาด และ MIME type เพื่อแสดงหน้าดาวน์โหลด

File contents go from your browser directly to your own Drive and never pass through our servers. We store only the Drive file ID, name, size and MIME type so the download page can be shown.

Subdomain ฟรี · Free subdomains

ลงทะเบียนด้วยการเข้าสู่ระบบ GitHub เราเก็บชื่อผู้ใช้ GitHub (และ ID) ของ owner/co-owner ชื่อ subdomain และ DNS record ที่คุณตั้ง ข้อมูลนี้อยู่ใน repository สาธารณะ จึงใครก็ดูได้ อย่าใส่ข้อมูลส่วนตัวใน record (เช่น ค่า TXT) เราไม่เก็บรหัสผ่านหรืออีเมล GitHub ของคุณ DNS record ถูกส่งไปที่ Cloudflare ซึ่งเป็นผู้ให้บริการ DNS

Registration uses GitHub sign-in. We store the GitHub username (and ID) of owners/co-owners, the subdomain name and the DNS records you set. This data lives in a public repository, so anyone can see it. Do not put personal information in records (e.g. TXT values). We do not store your GitHub password or email. DNS records are sent to Cloudflare, our DNS provider.

ข้อมูลทางเทคนิค · Technical data

เราไม่เก็บ log คำขอหรือ rate-limit ตาม IP ในโค้ดของเราเอง แต่ Cloudflare และ Vercel ประมวลผลข้อมูลคำขอมาตรฐาน เช่น IP เบราว์เซอร์ และเวลา เพื่อความปลอดภัย การป้องกัน abuse การแคช และสถิติรวม (รวมถึง Cloudflare Web Analytics/RUM และเครื่องมือ observability ของ Vercel) ระยะเวลาเก็บเป็นไปตามนโยบายของผู้ให้บริการเหล่านั้น เราไม่ใช้ข้อมูลนี้เพื่อโฆษณา

We do not keep our own request logs or per-IP rate limits in our code. However, Cloudflare and Vercel process standard request data such as IP address, browser type and timestamps for security, abuse prevention, caching and aggregate statistics (including Cloudflare Web Analytics/RUM and Vercel's observability tools). Retention follows those providers' policies. We do not use this data for advertising.

ที่เก็บในเบราว์เซอร์ · Browser storage

secret key และธีมที่เลือกเก็บใน local storage ของเบราว์เซอร์คุณ เราไม่ใช้คุกกี้โฆษณา

Your secret key and theme preference are kept in your browser's local storage. We do not use advertising cookies.

ข้อมูลผู้ใช้ Google · Google user data

ฟีเจอร์ Google Drive (ไม่บังคับ) ใช้ Google Sign-In ขอสิทธิ์ 3 รายการ:

  • https://www.googleapis.com/auth/drive.file — เห็นและจัดการเฉพาะไฟล์/โฟลเดอร์ที่แอปสร้าง หรือที่คุณเปิดผ่านแอป ไม่ให้เข้าถึงไฟล์อื่นใน Drive
  • openid และ https://www.googleapis.com/auth/userinfo.email — ให้เห็นที่อยู่อีเมลของบัญชีที่เชื่อมต่อ

เราไม่ขอรายชื่อติดต่อ ปฏิทิน กล่องอีเมล หรือข้อมูล Google อื่น

สิ่งที่เราทำกับสิทธิ์นี้

  • สร้าง (หรือใช้ซ้ำ) โฟลเดอร์ชื่อ go.thatako.net ใน Drive ของคุณ
  • อัปโหลดไฟล์ที่คุณเลือกเข้าโฟลเดอร์นั้น
  • ตั้งไฟล์เป็น "ทุกคนที่มีลิงก์ดูได้" เพื่อให้ผู้ที่คุณแชร์ลิงก์ให้ดาวน์โหลดได้
  • อ่านชื่อ ขนาด ประเภท และความเป็นเจ้าของไฟล์ เพื่อตรวจสอบและแสดงหน้าดาวน์โหลด
  • อ่านอีเมลและโควตาพื้นที่ แสดงให้คุณเห็นในเบราว์เซอร์ของคุณเท่านั้น เพื่อบอกว่าเชื่อมบัญชีไหนและพื้นที่พอหรือไม่

Access token

token อยู่ในหน่วยความจำของเบราว์เซอร์และหมดอายุราว 1 ชั่วโมง เมื่ออัปโหลดเสร็จ token จะถูกส่งหนึ่งครั้งผ่าน HTTPS มาที่เซิร์ฟเวอร์ (go.thatako.net) เพื่อยืนยันกับ Google ว่าไฟล์ที่ระบุมีอยู่ ไม่อยู่ในถังขยะ และเป็นของคุณ เซิร์ฟเวอร์ใช้ token ตรวจครั้งเดียวแล้วทิ้ง เราไม่เก็บ ไม่บันทึก และไม่นำ token กลับมาใช้ และไม่ได้รับ refresh token เราไม่เก็บอีเมลหรือข้อมูลโปรไฟล์ Google ของคุณบนเซิร์ฟเวอร์

The optional Google Drive feature uses Google Sign-In and requests three scopes:

  • https://www.googleapis.com/auth/drive.file — see and manage only files and folders the app created or that you opened with it. It does not give access to your other Drive files.
  • openid and https://www.googleapis.com/auth/userinfo.email — lets us see the email address of the connected account.

We do not request contacts, calendar, mailbox or any other Google data.

What we do with that access

  • Create (or reuse) a folder named go.thatako.net in your Drive.
  • Upload the files you select into it.
  • Set each file to "Anyone with the link can view" so people you share the link with can download it.
  • Read each file's name, size, type and ownership to verify it and show the download page.
  • Read your email and storage quota, shown only to you in your own browser so you know which account is connected and whether you have enough space.

Access tokens

The token stays in your browser's memory and expires after about an hour. When an upload finishes, it is sent once over HTTPS to our server (go.thatako.net) to confirm with Google that the listed files exist, are not in the trash and are owned by you. The server uses it for that single check and discards it. We never store, log or reuse tokens, and never receive a refresh token. We do not store your Google email or profile data on our servers.

การใช้และถ่ายโอนข้อมูลที่ได้รับจาก Google APIs เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use เราใช้ข้อมูลผู้ใช้ Google เพื่อให้ฟีเจอร์อัปโหลดที่คุณร้องขอเท่านั้น ไม่ถ่ายโอนให้ผู้อื่นยกเว้นเพื่อให้ฟีเจอร์ทำงานหรือปฏิบัติตามกฎหมาย ไม่ใช้เพื่อโฆษณา และไม่มีมนุษย์อ่านข้อมูลนั้น ยกเว้นเมื่อได้รับความยินยอมจากคุณ จำเป็นเพื่อความปลอดภัยหรือสอบสวน abuse หรือกฎหมายกำหนด
The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. We use Google user data only to provide the upload feature you ask for, do not transfer it to others except as needed to provide that feature or comply with law, do not use it for advertising, and no humans read it, except with your consent, where needed for security or investigating abuse, or where the law requires.

การเก็บรักษาและการลบ · Retention and deletion

  • Subdomain ลบได้ที่หน้าจัดการ ระเบียนปัจจุบันจะถูกลบ แต่ประวัติ commit ใน GitHub อาจยังเก็บชื่อผู้ใช้และ record เดิมไว้
  • เพิกถอนสิทธิ์แอปต่อบัญชี Google ได้ที่ myaccount.google.com/permissions
  • หากต้องการลบระเบียนแต่ไม่มี key แล้ว อีเมลมาพร้อมลิงก์ เราจะพิจารณาตามที่ยืนยันได้
  • Server files are deleted automatically on expiry; database records follow shortly after.
  • Short links and Drive links stay until you delete them. Deleting at go.thatako.net removes our record immediately.
  • Google Drive files are yours. Deleting a link does not delete the file from Drive; delete it there if you want it gone. Trashing the file or removing sharing breaks the download page.
  • Subdomains can be deleted on the management page. The current record is removed, but the GitHub commit history may still contain the old username and records.
  • Revoke the app's Google access at myaccount.google.com/permissions.
  • If you want a record removed but no longer have your key, email us with the link and we will consider it based on what we can verify.

ความปลอดภัย · Security

ทราฟฟิกทั้งหมดใช้ HTTPS โทเค็นอัปโหลดมีลายเซ็นและอายุสั้น ไฟล์ดาวน์โหลดส่งเป็น attachment และปิด content sniffing และหน้าดาวน์โหลดทำงานภายใต้ Content Security Policy ที่เข้มงวด ไม่มีระบบใดปลอดภัยสมบูรณ์ เราจึงรับประกันความปลอดภัยเด็ดขาดไม่ได้ และ secret key ที่เก็บแบบข้อความธรรมดา (ดูด้านบน) หมายความว่าหากฐานข้อมูลรั่ว key อาจรั่วด้วย

All traffic uses HTTPS. Upload tokens are signed and short-lived, downloads are served as attachments with content-sniffing disabled, and the download page runs under a strict Content Security Policy. No system is perfectly secure, so we cannot guarantee absolute security, and because secret keys are stored as plain text (see above), a database leak could expose them.
