ข้อกำหนดการใช้งาน ติดต่อ

เราคือใคร

thatako.net เป็นโครงการอาสาสมัครสำหรับนักเรียนและครูโรงเรียนท่าตะโกพิทยาคม ประเทศไทย ดำเนินงานโดยนักพัฒนาซึ่งเป็นนักเรียนชื่อ aitji (สุริยะ อินชู) ซึ่งทำหน้าที่เป็นผู้ควบคุมข้อมูลตามนโยบายนี้

บริการที่ครอบคลุม ได้แก่ บริการย่อลิงก์ แชร์ไฟล์ และสร้าง QR code ที่ go.thatako.net รวมถึงบริการ subdomain ฟรีที่ id.thatako.net

ซอร์สโค้ดเผยแพร่สาธารณะที่ github.com/aitji/thatako.net และ github.com/aitji/id.thatako.net

ข้อมูลที่เราเก็บ

ลิงก์และไฟล์

เมื่อคุณสร้างลิงก์ เราจะจัดเก็บ slug (ชื่อท้ายลิงก์) ปลายทาง วันที่สร้าง และ secret key ที่สุ่มขึ้นในเบราว์เซอร์ของคุณไว้ในฐานข้อมูล Cloudflare KV

secret key จัดเก็บเป็นข้อความธรรมดา ไม่ได้ผ่านการแฮช เราทำเช่นนี้เพื่อช่วยครูกู้คืนลิงก์ในกรณีที่ทำ key หาย ซึ่งหมายความว่าผู้ดูแลระบบสามารถเห็น key ได้

เราไม่ขอชื่อ อีเมล หรือรหัสผ่าน และไม่บันทึกว่าใครคลิกลิงก์ ระบบอาจแคชลิงก์ที่มีผู้ใช้บ่อยเพื่อให้เปลี่ยนเส้นทางได้รวดเร็ว โดยแคชดังกล่าวไม่มีข้อมูลผู้เข้าชม

ไฟล์ที่จัดเก็บบนเซิร์ฟเวอร์ของเรา

หากคุณเลือกจัดเก็บไฟล์บนเซิร์ฟเวอร์ เราจะเก็บเนื้อหาไฟล์ ชื่อไฟล์ ขนาด และ MIME type ไว้ใน Cloudflare R2 โดยระบบจะกำหนดภูมิภาคจัดเก็บให้อัตโนมัติ ไฟล์จะถูกเก็บไว้จนถึงวันหมดอายุที่คุณเลือก ซึ่งอยู่ระหว่าง 7–90 วัน จากนั้นระบบจะลบไฟล์โดยอัตโนมัติ

ไฟล์ใน Google Drive ของคุณ

เนื้อหาไฟล์จะส่งจากเบราว์เซอร์ของคุณไปยัง Google Drive ของคุณโดยตรง โดยไม่ผ่านเซิร์ฟเวอร์ของเรา เราจัดเก็บเฉพาะ Drive file ID ชื่อไฟล์ ขนาด และ MIME type เพื่อใช้แสดงหน้าดาวน์โหลด

Subdomain ฟรี

การลงทะเบียนใช้การเข้าสู่ระบบด้วย GitHub เราจัดเก็บชื่อผู้ใช้และ ID ของ GitHub สำหรับเจ้าของหลักและเจ้าของร่วม ชื่อ subdomain และ DNS record ที่คุณตั้งค่าไว้

ข้อมูลเหล่านี้อยู่ใน repository สาธารณะ ทุกคนจึงสามารถดูได้ โปรดอย่าใส่ข้อมูลส่วนตัวไว้ใน record เช่น ค่า TXT เราไม่จัดเก็บรหัสผ่านหรืออีเมล GitHub ของคุณ และ DNS record จะถูกส่งไปยัง Cloudflare ซึ่งเป็นผู้ให้บริการ DNS ของเรา

ข้อมูลทางเทคนิค

เราไม่เก็บบันทึกคำขอใช้งานหรือจำกัดอัตราการใช้งานแยกตาม IP ในโค้ดของเราเอง อย่างไรก็ตาม Cloudflare และ Vercel ประมวลผลข้อมูลคำขอมาตรฐาน เช่น ที่อยู่ IP ประเภทเบราว์เซอร์ และเวลาใช้งาน เพื่อรักษาความปลอดภัย ป้องกันการใช้งานในทางที่ไม่เหมาะสม รองรับการแคช และจัดทำสถิติภาพรวม ซึ่งรวมถึง Cloudflare Web Analytics/RUM และเครื่องมือสังเกตการณ์ระบบของ Vercel

ระยะเวลาจัดเก็บข้อมูลเป็นไปตามนโยบายของผู้ให้บริการแต่ละราย เราไม่นำข้อมูลดังกล่าวไปใช้เพื่อการโฆษณา

ข้อมูลที่จัดเก็บในเบราว์เซอร์

secret key และธีมที่คุณเลือกจะจัดเก็บไว้ใน local storage ของเบราว์เซอร์ เราไม่ใช้คุกกี้เพื่อการโฆษณา

ข้อมูลผู้ใช้ Google

ฟีเจอร์ Google Drive เป็นฟีเจอร์ที่เลือกใช้ได้ โดยใช้ Google Sign-In และขอสิทธิ์ 3 รายการ ได้แก่

  • https://www.googleapis.com/auth/drive.file — ดูและจัดการได้เฉพาะไฟล์หรือโฟลเดอร์ ที่แอปสร้างขึ้น หรือที่คุณเปิดผ่านแอปเท่านั้น สิทธิ์นี้ไม่อนุญาตให้แอปเข้าถึงไฟล์อื่นใน Drive ของคุณ
  • openid และ https://www.googleapis.com/auth/userinfo.email — ใช้ดูอีเมลของบัญชีที่เชื่อมต่อ

เราไม่ขอสิทธิ์เข้าถึงรายชื่อติดต่อ ปฏิทิน กล่องจดหมาย หรือข้อมูล Google อื่น ๆ

เราใช้สิทธิ์ดังกล่าวทำอะไรบ้าง

  • สร้างหรือใช้โฟลเดอร์ชื่อ go.thatako.net ที่มีอยู่แล้วใน Drive ของคุณ
  • อัปโหลดไฟล์ที่คุณเลือกไปยังโฟลเดอร์นั้น
  • ตั้งค่าไฟล์ให้เป็น "ทุกคนที่มีลิงก์สามารถดูได้" เพื่อให้ผู้ที่คุณแชร์ลิงก์ด้วยดาวน์โหลดไฟล์ได้
  • อ่านชื่อ ขนาด ประเภท และข้อมูลเจ้าของไฟล์ เพื่อตรวจสอบไฟล์และแสดงหน้าดาวน์โหลด
  • อ่านอีเมลและโควตาพื้นที่จัดเก็บ แล้วแสดงข้อมูลดังกล่าวให้คุณเห็นในเบราว์เซอร์ของคุณเท่านั้น เพื่อแจ้งว่ากำลังเชื่อมต่อบัญชีใดและมีพื้นที่เพียงพอหรือไม่

Access token

token จะอยู่ในหน่วยความจำของเบราว์เซอร์และหมดอายุภายในประมาณ 1 ชั่วโมง เมื่ออัปโหลดเสร็จ token จะถูกส่งผ่าน HTTPS ไปยังเซิร์ฟเวอร์ของเรา (go.thatako.net) หนึ่งครั้ง เพื่อยืนยันกับ Google ว่าไฟล์ที่ระบุมีอยู่จริง ไม่อยู่ในถังขยะ และเป็นของคุณ จากนั้นเซิร์ฟเวอร์จะใช้ token เพื่อตรวจสอบครั้งนั้นแล้วทิ้งไป

เราไม่จัดเก็บ ไม่บันทึกการใช้งาน หรือนำ token กลับมาใช้ซ้ำ และเราไม่ได้รับ refresh token นอกจากนี้ เราไม่จัดเก็บอีเมลหรือข้อมูลโปรไฟล์ Google ของคุณบนเซิร์ฟเวอร์

การใช้และการส่งต่อข้อมูลที่ได้รับจาก Google APIs เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use เราใช้ข้อมูลผู้ใช้ Google เพื่อให้บริการฟีเจอร์อัปโหลดที่คุณร้องขอเท่านั้น และจะไม่ส่งต่อให้ผู้อื่น เว้นแต่จำเป็นต่อการให้บริการหรือปฏิบัติตามกฎหมาย เราไม่ใช้ข้อมูลดังกล่าวเพื่อการโฆษณา และไม่มีบุคคลเข้าถึงข้อมูล เว้นแต่คุณให้ความยินยอม จำเป็นต่อการรักษาความปลอดภัยหรือสอบสวนการใช้งานในทางที่ไม่เหมาะสม หรือกฎหมายกำหนด

เราใช้ข้อมูลอย่างไร

  • เปลี่ยนเส้นทางลิงก์ย่อและแสดงหน้าดาวน์โหลดไฟล์
  • ให้คุณดู แก้ไข และลบลิงก์ที่สร้างด้วย key ของคุณ
  • จัดการข้อจำกัดด้านพื้นที่จัดเก็บ และป้องกันการใช้งานในทางที่ไม่เหมาะสม ฟิชชิง และมัลแวร์
  • จัดการ DNS ของ subdomain ที่คุณลงทะเบียน
  • ดูแลความปลอดภัยและให้บริการทำงานได้ตามปกติ

ฐานทางกฎหมายตาม PDPA: ความยินยอมของคุณ เช่น เมื่อเชื่อมต่อ Google หรือสร้างลิงก์ การให้บริการตามที่คุณร้องขอ และประโยชน์โดยชอบด้วยกฎหมายของเราในการรักษาความปลอดภัย และป้องกันการใช้งานในทางที่ไม่เหมาะสม

เราไม่ขายข้อมูลส่วนบุคคล ไม่แสดงโฆษณา และไม่สร้างโปรไฟล์เพื่อใช้ในการโฆษณา

การเปิดเผยและการโอนข้อมูลไปต่างประเทศ

ผู้ที่มีลิงก์สามารถเปิดหน้าและดาวน์โหลดไฟล์ที่อยู่ในลิงก์นั้นได้ โปรดถือว่าลิงก์ทุกลิงก์เป็นลิงก์สาธารณะ

เราเปิดเผยข้อมูลให้ผู้ให้บริการเท่าที่จำเป็นต่อการให้บริการ ได้แก่ Cloudflare (โฮสต์ พื้นที่จัดเก็บ และ DNS), Vercel (เว็บไซต์), GitHub (ทะเบียน subdomain และการเข้าสู่ระบบ) และ Google (เมื่อคุณเลือกใช้ Drive) นอกจากนี้ เราอาจเปิดเผยข้อมูลเมื่อกฎหมายกำหนด หรือเพื่อป้องกันการใช้งานในทางที่ไม่เหมาะสม

ผู้ให้บริการเหล่านี้ตั้งอยู่หรือประมวลผลข้อมูลนอกประเทศไทย เช่น ในสหรัฐอเมริกา การใช้บริการถือว่าคุณรับทราบว่าข้อมูลอาจถูกโอนไปต่างประเทศ เราเลือกใช้ผู้ให้บริการที่มีแนวปฏิบัติด้านการคุ้มครองข้อมูลตามมาตรฐานที่เป็นที่ยอมรับในระดับสากล

การเก็บรักษาและการลบข้อมูล

  • ไฟล์บนเซิร์ฟเวอร์: ระบบจะลบไฟล์โดยอัตโนมัติเมื่อหมดอายุ ส่วนระเบียนในฐานข้อมูลจะถูกลบตามหลังในเวลาไม่นาน
  • ลิงก์ย่อและลิงก์ Drive: จะคงอยู่จนกว่าคุณจะลบ เมื่อลบที่ go.thatako.net ระเบียนของเราจะถูกลบทันที
  • ไฟล์ใน Google Drive: ไฟล์เป็นของคุณ การลบลิงก์ไม่ได้ลบไฟล์ออกจาก Drive หากต้องการลบไฟล์ โปรดลบจาก Drive โดยตรง การย้ายไฟล์ไปยังถังขยะหรือยกเลิกการแชร์ จะทำให้หน้าดาวน์โหลดใช้งานไม่ได้
  • Subdomain: คุณลบได้จากหน้าจัดการ ระบบจะลบระเบียนปัจจุบันออก แต่ประวัติ commit ใน GitHub อาจยังมีชื่อผู้ใช้และ record เดิมอยู่
  • คุณเพิกถอนสิทธิ์แอปจากบัญชี Google ได้ที่ myaccount.google.com/permissions
  • หากต้องการลบระเบียนแต่ไม่มี key แล้ว โปรดส่งอีเมลพร้อมลิงก์ที่เกี่ยวข้อง เราจะพิจารณาจากข้อมูลที่ตรวจสอบได้

ความปลอดภัย

การรับส่งข้อมูลทั้งหมดใช้ HTTPS โทเค็นอัปโหลดมีลายเซ็นและมีอายุสั้น ไฟล์ดาวน์โหลดจะถูกส่งในรูปแบบไฟล์แนบโดยปิดการตรวจจับประเภทเนื้อหาอัตโนมัติ และหน้าดาวน์โหลดทำงานภายใต้ Content Security Policy ที่เข้มงวด

อย่างไรก็ตาม ไม่มีระบบใดปลอดภัยได้อย่างสมบูรณ์ เราจึงรับประกันความปลอดภัยอย่างเด็ดขาดไม่ได้ นอกจากนี้ secret key จัดเก็บเป็นข้อความธรรมดาตามที่อธิบายไว้ข้างต้น หากฐานข้อมูลรั่วไหล key ก็อาจรั่วไหลไปด้วย

เด็กและนักเรียน

บริการเปิดให้ทุกคนใช้งาน และผู้ใช้ส่วนใหญ่เป็นนักเรียนระดับมัธยม เราไม่ได้ตรวจสอบอายุผู้ใช้ และไม่มีเจตนาเก็บข้อมูลส่วนบุคคลนอกเหนือจากที่ระบุไว้ในนโยบายนี้ บริการนี้ไม่ได้ออกแบบมาสำหรับเด็กอายุต่ำกว่า 13 ปี

หากคุณยังเป็นผู้เยาว์ โปรดให้ผู้ปกครอง ผู้ปกครองตามกฎหมาย หรือครูรับทราบว่าคุณใช้บริการนี้ หากเชื่อว่าเด็กส่งข้อมูลส่วนบุคคลมาโดยไม่เหมาะสม โปรดแจ้งเราที่ privacy@thatako.net เพื่อให้เราลบข้อมูล บัญชี Google อยู่ภายใต้ข้อกำหนดอายุขั้นต่ำของ Google

สิทธิของคุณ

ภายใต้พระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล (PDPA) คุณมีสิทธิขอเข้าถึง แก้ไข ลบ หรือระงับการใช้ข้อมูลส่วนบุคคลที่เราเก็บไว้ คัดค้านการประมวลผล ขอรับสำเนาข้อมูล และถอนความยินยอมได้ทุกเมื่อ

ติดต่อเราได้ที่ privacy@thatako.net เนื่องจากเราไม่ได้เก็บชื่อหรืออีเมล เราอาจขอให้คุณยืนยันว่าคุณเป็นผู้ถือ key หรือลิงก์ที่เกี่ยวข้อง หรือเป็นเจ้าของบัญชี GitHub ที่ใช้กับ subdomain ก่อนดำเนินการ

หากคุณไม่พอใจต่อการดำเนินการของเรา คุณมีสิทธิร้องเรียนต่อสำนักงานคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล (สคส./PDPC)

การเปลี่ยนแปลงนโยบาย

เราอาจปรับปรุงนโยบายนี้เป็นครั้งคราว วันที่มีผลที่แสดงไว้ด้านบนคือวันที่ของฉบับล่าสุด เราจะแจ้งการเปลี่ยนแปลงสำคัญที่ thatako.net การใช้บริการต่อหลังจากนโยบายมีการปรับปรุง ถือว่าคุณยอมรับนโยบายฉบับที่ปรับปรุงแล้ว
