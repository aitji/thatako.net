เราคือใคร · Who we are

thatako.net เป็นโครงการอาสาสมัครสำหรับนักเรียนและครูโรงเรียนท่าตะโกพิทยาคม ประเทศไทย ดำเนินงานโดยนักพัฒนาซึ่งเป็นนักเรียนชื่อ aitji (สุริยะ อินชู) ซึ่งทำหน้าที่เป็นผู้ควบคุมข้อมูลตามนโยบายนี้ บริการที่ครอบคลุม ได้แก่ บริการย่อลิงก์ แชร์ไฟล์ และสร้าง QR code ที่ go.thatako.net รวมถึงบริการ subdomain ฟรีที่ id.thatako.net ซอร์สโค้ดเผยแพร่สาธารณะที่ github.com/aitji/thatako.net และ github.com/aitji/id.thatako.net

thatako.net is a volunteer project for students and teachers of Thatakophittayakom School in Thailand. It is run by a student developer, aitji (Suriya Inchoo), who is the data controller for this policy. The services covered include the URL shortener, file sharing and QR code generator at go.thatako.net, and the free subdomains at id.thatako.net. ข้อมูลที่เราเก็บ · Information we collect

ลิงก์และไฟล์ · Links and files

เมื่อคุณสร้างลิงก์ เราจะจัดเก็บ slug (ชื่อท้ายลิงก์) ปลายทาง วันที่สร้าง และ secret key ที่สุ่มขึ้นในเบราว์เซอร์ของคุณไว้ในฐานข้อมูล Cloudflare KV secret key จัดเก็บเป็นข้อความธรรมดา ไม่ได้ผ่านการแฮช เราทำเช่นนี้เพื่อช่วยครูกู้คืนลิงก์ในกรณีที่ทำ key หาย ซึ่งหมายความว่าผู้ดูแลระบบสามารถเห็น key ได้ เราไม่ขอชื่อ อีเมล หรือรหัสผ่าน และไม่บันทึกว่าใครคลิกลิงก์ ระบบอาจแคชลิงก์ที่มีผู้ใช้บ่อยเพื่อให้เปลี่ยนเส้นทางได้รวดเร็ว โดยแคชดังกล่าวไม่มีข้อมูลผู้เข้าชม

When you create a link, we store its slug, destination, creation date and a random secret key generated in your browser in our database (Cloudflare KV). The secret key is stored as plain text, not hashed. This lets us help teachers recover links if they lose a key, but it also means the operator can see the keys. We do not ask for your name, email address or password, and we do not record who clicks a link. The system may cache frequently used links to redirect them quickly; this cache contains no visitor information.

ไฟล์บนเซิร์ฟเวอร์ · Files on our server

หากคุณเลือกจัดเก็บไฟล์บนเซิร์ฟเวอร์ เราจะเก็บเนื้อหาไฟล์ ชื่อไฟล์ ขนาด และ MIME type ไว้ใน Cloudflare R2 โดยระบบจะกำหนดภูมิภาคจัดเก็บให้อัตโนมัติ ไฟล์จะถูกเก็บไว้จนถึงวันหมดอายุที่คุณเลือก ซึ่งอยู่ระหว่าง 7–90 วัน จากนั้นระบบจะลบไฟล์โดยอัตโนมัติ

If you choose server storage, we keep the file contents, name, size and MIME type in Cloudflare R2. The storage region is assigned automatically. Files remain there until your selected expiry date (7–90 days), after which they are deleted automatically.

ไฟล์ใน Google Drive ของคุณ · Files on your Google Drive

เนื้อหาไฟล์จะส่งจากเบราว์เซอร์ของคุณไปยัง Google Drive ของคุณโดยตรง โดยไม่ผ่านเซิร์ฟเวอร์ของเรา เราจัดเก็บเฉพาะ Drive file ID ชื่อไฟล์ ขนาด และ MIME type เพื่อใช้แสดงหน้าดาวน์โหลด

File contents go directly from your browser to your own Google Drive and never pass through our servers. We store only the Drive file ID, name, size and MIME type so we can display the download page.

Subdomain ฟรี · Free subdomains

การลงทะเบียนใช้การเข้าสู่ระบบด้วย GitHub เราจัดเก็บชื่อผู้ใช้และ ID ของ GitHub สำหรับเจ้าของหลักและเจ้าของร่วม ชื่อ subdomain และ DNS record ที่คุณตั้งค่าไว้ ข้อมูลเหล่านี้อยู่ใน repository สาธารณะ ทุกคนจึงสามารถดูได้ โปรดอย่าใส่ข้อมูลส่วนตัวไว้ใน record เช่น ค่า TXT เราไม่จัดเก็บรหัสผ่านหรืออีเมล GitHub ของคุณ และ DNS record จะถูกส่งไปยัง Cloudflare ซึ่งเป็นผู้ให้บริการ DNS ของเรา

Registration uses GitHub sign-in. We store the GitHub usernames and IDs of owners and co-owners, the subdomain name, and the DNS records you set. This data is in a public repository, so anyone can see it. Do not put personal information in DNS records, including TXT values. We do not store your GitHub password or email address. DNS records are sent to Cloudflare, our DNS provider.

ข้อมูลทางเทคนิค · Technical data

เราไม่เก็บบันทึกคำขอใช้งานหรือจำกัดอัตราการใช้งานแยกตาม IP ในโค้ดของเราเอง อย่างไรก็ตาม Cloudflare และ Vercel ประมวลผลข้อมูลคำขอมาตรฐาน เช่น ที่อยู่ IP ประเภทเบราว์เซอร์ และเวลาใช้งาน เพื่อรักษาความปลอดภัย ป้องกันการใช้งานในทางที่ไม่เหมาะสม รองรับการแคช และจัดทำสถิติภาพรวม ซึ่งรวมถึง Cloudflare Web Analytics/RUM และเครื่องมือสังเกตการณ์ระบบของ Vercel ระยะเวลาจัดเก็บข้อมูลเป็นไปตามนโยบายของผู้ให้บริการ เราไม่นำข้อมูลดังกล่าวไปใช้เพื่อการโฆษณา

Our own code does not keep request logs or apply per-IP rate limits. However, Cloudflare and Vercel process standard request data, such as IP address, browser type and timestamps, for security, abuse prevention, caching and aggregate statistics. This includes Cloudflare Web Analytics/RUM and Vercel’s observability tools. Retention follows each provider’s policies. We do not use this data for advertising.

ที่เก็บในเบราว์เซอร์ · Browser storage

secret key และธีมที่คุณเลือกจะจัดเก็บไว้ใน local storage ของเบราว์เซอร์ เราไม่ใช้คุกกี้เพื่อการโฆษณา

Your secret key and theme preference are stored in your browser’s local storage. We do not use advertising cookies.

ข้อมูลผู้ใช้ Google · Google user data

ฟีเจอร์ Google Drive เป็นฟีเจอร์ที่เลือกใช้ได้ โดยใช้ Google Sign-In และขอสิทธิ์ 3 รายการ ได้แก่

  • https://www.googleapis.com/auth/drive.file — ดูและจัดการได้เฉพาะไฟล์หรือโฟลเดอร์ ที่แอปสร้างขึ้น หรือที่คุณเปิดผ่านแอปเท่านั้น สิทธิ์นี้ไม่อนุญาตให้แอปเข้าถึงไฟล์อื่นใน Drive ของคุณ
  • openid และ https://www.googleapis.com/auth/userinfo.email — ใช้ดูอีเมลของบัญชีที่เชื่อมต่อ

เราไม่ขอสิทธิ์เข้าถึงรายชื่อติดต่อ ปฏิทิน กล่องจดหมาย หรือข้อมูล Google อื่น ๆ

เราใช้สิทธิ์ดังกล่าวทำอะไรบ้าง

  • สร้างหรือใช้โฟลเดอร์ชื่อ go.thatako.net ที่มีอยู่แล้วใน Drive ของคุณ
  • อัปโหลดไฟล์ที่คุณเลือกไปยังโฟลเดอร์นั้น
  • ตั้งค่าไฟล์เป็น “ทุกคนที่มีลิงก์สามารถดูได้” เพื่อให้ผู้ที่คุณแชร์ลิงก์ด้วยดาวน์โหลดไฟล์ได้
  • อ่านชื่อ ขนาด ประเภท และข้อมูลเจ้าของไฟล์ เพื่อตรวจสอบไฟล์และแสดงหน้าดาวน์โหลด
  • อ่านอีเมลและโควตาพื้นที่จัดเก็บ แล้วแสดงข้อมูลให้คุณเห็นในเบราว์เซอร์ของคุณเท่านั้น เพื่อแจ้งว่ากำลังเชื่อมต่อบัญชีใดและมีพื้นที่เพียงพอหรือไม่

Access token

token จะอยู่ในหน่วยความจำของเบราว์เซอร์และหมดอายุภายในประมาณ 1 ชั่วโมง เมื่ออัปโหลดเสร็จ token จะถูกส่งผ่าน HTTPS ไปยังเซิร์ฟเวอร์ของเรา (go.thatako.net) หนึ่งครั้ง เพื่อยืนยันกับ Google ว่าไฟล์ที่ระบุมีอยู่จริง ไม่อยู่ในถังขยะ และเป็นของคุณ จากนั้นเซิร์ฟเวอร์จะใช้ token เพื่อตรวจสอบครั้งนั้นแล้วทิ้งไป เราไม่จัดเก็บ ไม่บันทึกการใช้งาน หรือนำ token กลับมาใช้ซ้ำ และเราไม่ได้รับ refresh token เราไม่จัดเก็บอีเมลหรือข้อมูลโปรไฟล์ Google ของคุณบนเซิร์ฟเวอร์

The optional Google Drive feature uses Google Sign-In and requests three scopes:

  • https://www.googleapis.com/auth/drive.file — lets the app see and manage only files and folders it created or that you opened with it. It does not give the app access to your other Drive files.
  • openid and https://www.googleapis.com/auth/userinfo.email — let us see the email address of the connected account.

We do not request access to your contacts, calendar, mailbox or any other Google data.

What we do with that access

  • Create or reuse a folder named go.thatako.net in your Drive.
  • Upload the files you select into that folder.
  • Set files to “Anyone with the link can view” so people you share the link with can download them.
  • Read each file’s name, size, type and ownership to verify it and show the download page.
  • Read your email address and storage quota, displaying them only in your browser so you can see which account is connected and whether you have enough space.

Access tokens

The token stays in your browser’s memory and expires after about one hour. When an upload finishes, it is sent once over HTTPS to our server (go.thatako.net) so we can confirm with Google that the listed files exist, are not in the trash and belong to you. The server uses the token for that single check and then discards it. We never store, log or reuse tokens, and we never receive a refresh token. We do not store your Google email address or profile data on our servers.

Our use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements. We use Google user data only to provide the upload feature you request. We do not transfer it to others except as needed to provide that feature or comply with the law, and we do not use it for advertising. No person reads the data except with your consent, when necessary for security or to investigate abuse, or when required by law.

Anyone with a link can open its page and download the files behind it. Treat every link as public. We share data with providers only as needed to run the service: Cloudflare (hosting, storage and DNS), Vercel (website), GitHub (subdomain registry and sign-in), and Google (when you choose Drive). These providers are located or process data outside Thailand, including in the United States. By using the service, you acknowledge that this cross-border transfer may take place. We choose providers with internationally recognised data protection practices.
