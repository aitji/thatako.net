บริการนี้คืออะไร

thatako.net เป็นโครงการอาสาสมัครที่ให้บริการโดยไม่คิดค่าใช้จ่าย สร้างและดูแลโดยนักเรียน (aitji) สำหรับนักเรียนและครูโรงเรียนท่าตะโกพิทยาคม โรงเรียนให้ครูสนับสนุนชื่อโดเมนดังกล่าว (ดูหน้าเกี่ยวกับ) แต่โครงการนี้ ไม่ใช่บริการอย่างเป็นทางการของโรงเรียน เว้นแต่จะระบุไว้เป็นอย่างอื่นในหน้าใดหน้าหนึ่ง

บริการนี้จัดให้ "ตามสภาพที่เป็นอยู่" และอาจมีการเปลี่ยนแปลง จำกัดการใช้งาน หรือยุติได้ทุกเมื่อ

ใครใช้บริการได้บ้าง

ทุกคนสามารถใช้บริการได้ ไม่จำเป็นต้องเป็นสมาชิกของโรงเรียน อย่างไรก็ตาม บริการนี้จัดทำขึ้นเพื่อการเรียนรู้และงานของโรงเรียนเป็นหลัก เราอาจจำกัดหรือปฏิเสธการใช้งานที่ไม่เกี่ยวข้องกับวัตถุประสงค์ดังกล่าว หรือก่อภาระต่อระบบ

หากคุณอายุต่ำกว่า 18 ปี โปรดให้ผู้ปกครอง ผู้ปกครองตามกฎหมาย หรือครูรับทราบก่อนใช้งาน และอย่าใส่ข้อมูลส่วนตัวของคุณหรือผู้อื่นไว้ในเนื้อหา บริการนี้ไม่ได้ออกแบบมาสำหรับเด็กอายุต่ำกว่า 13 ปี

Secret key (รหัสลับ)

คุณไม่จำเป็นต้องสมัครบัญชี ลิงก์จะจัดการด้วย secret key ที่เก็บไว้ในเบราว์เซอร์ของคุณ ผู้ที่มี key สามารถแก้ไขหรือลบลิงก์ของคุณได้ โปรดเก็บ key ไว้เป็นความลับและ สำรอง key ด้วยตนเอง

หากคุณทำ key หาย อาจไม่สามารถกู้คืนลิงก์ได้ เราอาจช่วยกู้คืนให้ตามดุลยพินิจ แต่ไม่มีวิธียืนยันตัวตนอย่างเป็นทางการ จึงอาจปฏิเสธคำขอหากไม่สามารถตรวจสอบได้อย่างสมเหตุสมผล ว่าลิงก์นั้นเป็นของคุณ โปรดอย่าพึ่งพาการกู้คืน key

เนื้อหาและลิงก์ของคุณ

คุณยังคงเป็นเจ้าของไฟล์และลิงก์ที่ส่งเข้ามา และเป็นผู้รับผิดชอบต่อเนื้อหาดังกล่าวแต่เพียงผู้เดียว คุณยืนยันว่ามีสิทธิ์แชร์เนื้อหานั้น และอนุญาตให้เราจัดเก็บ ส่งต่อ และแสดงเนื้อหา เท่าที่จำเป็นต่อการให้บริการเท่านั้น

ทุกอย่างแชร์ผ่านลิงก์ ผู้ที่มีลิงก์ไฟล์สามารถดาวน์โหลดไฟล์ได้ และผู้อื่นอาจคาดเดา slug ที่คุณกำหนดเองได้ อย่าอัปโหลดรหัสผ่าน เอกสารระบุตัวตน ข้อสอบที่ยังไม่เผยแพร่ หรือข้อมูลส่วนตัวและข้อมูลอ่อนไหวอื่น ๆ

ตัวเลือกการจัดเก็บไฟล์

  • จัดเก็บบนเซิร์ฟเวอร์ของเรา: มีข้อจำกัดด้านขนาด จำนวนไฟล์ และระยะเวลาจัดเก็บ (7–90 วัน) เมื่อไฟล์หมดอายุ ระบบจะลบอย่างถาวรและไม่สามารถกู้คืนได้ เราไม่มีระบบสำรองข้อมูลไฟล์
  • จัดเก็บใน Google Drive: ไฟล์จะอยู่ใน Drive ของคุณภายใต้บัญชีและข้อกำหนดของ Google และจะไม่หมดอายุจนกว่าคุณจะลบ ยกเลิกการแชร์ หรือย้ายไฟล์ไปยังถังขยะ เราไม่ได้เป็นผู้โฮสต์ไฟล์เหล่านี้ และไม่รับผิดชอบต่อบริการ โควตาพื้นที่ หรือความพร้อมใช้งานของ Google แอปจะตั้งค่าไฟล์เป็น "ทุกคนที่มีลิงก์สามารถดูได้" คุณเปลี่ยนการตั้งค่าหรือยกเลิกการแชร์ได้ทุกเมื่อใน Drive บัญชี Google ของโรงเรียนอาจบล็อกแอปจากผู้ให้บริการภายนอก ซึ่งอยู่นอกเหนือการควบคุมของเรา

Subdomain ฟรี (id.thatako.net)

  • ลงทะเบียนด้วยบัญชี GitHub ได้ ชื่อ subdomain ใช้ได้เฉพาะ a–z, 0–9 และเครื่องหมาย - บางชื่อสงวนไว้สำหรับระบบหรือโรงเรียน เช่น council, pr, go, api และ status
  • คุณเป็นเจ้าของหลัก (Primary Owner) และเพิ่มเจ้าของร่วม (Co-owner) ได้ เจ้าของหลักหรือเจ้าของร่วมสามารถแก้ไข DNS record ได้ แต่เฉพาะเจ้าของหลักเท่านั้นที่ลบโดเมนหรือเปลี่ยนเจ้าของได้
  • รองรับ record ประเภท CNAME, A, AAAA, TXT และ MX คุณเป็นผู้รับผิดชอบต่ออีเมลที่ได้รับผ่านโดเมนดังกล่าว
  • ข้อมูลการลงทะเบียนเป็นสาธารณะ: ชื่อ subdomain, DNS record และชื่อผู้ใช้ GitHub ของเจ้าของหลักและเจ้าของร่วมจัดเก็บอยู่ใน repository สาธารณะ ทุกคนจึงสามารถดูได้
  • ห้ามจองชื่อไว้โดยไม่มีการใช้งานจริง ห้ามแอบอ้างว่าเป็นเว็บไซต์ทางการของโรงเรียน และห้ามใช้โดเมนฟรีนี้เป็นฐานของบริการที่สร้างรายได้ อย่างไรก็ตาม คุณสามารถลงโฆษณาบนเว็บไซต์ของคุณเองได้ เช่น AdSense
  • เราอาจระงับหรือเรียกคืน subdomain ที่ละเมิดข้อกำหนด มีผู้รายงานว่าไม่เหมาะสม ปลายทางใช้งานไม่ได้เป็นเวลานานและติดต่อเจ้าของไม่ได้ หรือเป็นชื่อที่โรงเรียนจำเป็นต้องใช้

การใช้งานที่ห้าม

ห้ามใช้บริการเพื่อสร้าง จัดเก็บ หรือเชื่อมโยงไปยังเนื้อหาต่อไปนี้:

  • เนื้อหาลามกอนาจาร (NSFW) หรือเนื้อหาที่แสวงหาประโยชน์จากหรือเป็นอันตรายต่อผู้เยาว์
  • เนื้อหาที่ผิดกฎหมายในประเทศไทยหรือในประเทศที่คุณอยู่ รวมถึงเนื้อหาที่ละเมิดลิขสิทธิ์
  • ฟิชชิง มัลแวร์ สปายแวร์ ช่องโหว่ที่ใช้โจมตีระบบ (exploit) หรือไฟล์อันตรายอื่น ๆ
  • การคุกคาม การกลั่นแกล้ง วาจาสร้างความเกลียดชัง การข่มขู่ การเปิดเผยข้อมูลส่วนตัวของผู้อื่นโดยไม่ได้รับอนุญาต (doxxing) หรือเนื้อหาที่มุ่งโจมตีบุคคล รวมถึงนักเรียนและครู
  • การแอบอ้างเป็นครู เจ้าหน้าที่ หรือเว็บไซต์ทางการของโรงเรียน
  • ข้อสอบหรือเนื้อหาที่นำไปใช้ทุจริตในการสอบ
  • สแปม หรือลิงก์ที่ซ่อนปลายทางเพื่อหลอกลวงผู้อื่น

นอกจากนี้ ห้ามรบกวนหรือโจมตีระบบ ดึงข้อมูลในปริมาณมาก หลีกเลี่ยงข้อจำกัด เจาะเข้าระบบ หรือใช้บริการนี้เพื่อหลบเลี่ยงกฎของบริการอื่น

การรายงานและการดำเนินการ

เราตรวจสอบเนื้อหา เมื่อมีผู้รายงานเท่านั้น และไม่ได้สแกนไฟล์หรือเว็บไซต์ล่วงหน้า คุณรายงานได้ที่ abuse@thatako.net หรือผ่านหน้ารายงานการใช้งานที่ไม่เหมาะสม โดยระบุ URL หลักฐาน และเหตุผล

เนื่องจากโครงการดำเนินงานโดยอาสาสมัคร โดยทั่วไปเราจะตอบกลับภายในไม่กี่วัน แต่อาจใช้เวลานานขึ้นในช่วงสอบหรือวันหยุด กรณีฟิชชิง มัลแวร์ หรือเนื้อหาที่เป็นอันตรายอย่างชัดเจนจะได้รับการจัดการก่อน

เราอาจปิดใช้งานหรือลบลิงก์ ไฟล์ หรือ subdomain รวมถึงบล็อก key หรือที่อยู่ใด ๆ ได้ทุกเมื่อโดยไม่ต้องแจ้งล่วงหน้า และอาจรายงานเนื้อหาที่ผิดกฎหมายต่อหน่วยงานที่เกี่ยวข้อง หากเป็นไฟล์ที่โฮสต์บน Drive โปรดรายงานไปยัง Google ด้วย หากคุณเห็นว่าเราตัดสินใจไม่ถูกต้อง สามารถยื่นอุทธรณ์ได้ที่ abuse@thatako.net

ลิขสิทธิ์: หากเนื้อหาละเมิดผลงานของคุณ โปรดส่งอีเมลพร้อม (1) ลิงก์ไปยังเนื้อหาที่ละเมิด (2) ผลงานต้นฉบับหรือหลักฐานแสดงความเป็นเจ้าของ (3) ชื่อและช่องทางติดต่อ และ (4) คำยืนยันว่าคุณแจ้งโดยสุจริต เราอาจลบเนื้อหาหรือปิดการเข้าถึงเป็นการชั่วคราว และขอให้เจ้าของลิงก์ชี้แจง

บริการของ Google

หากคุณเชื่อมต่อ Google Drive คุณต้องยอมรับข้อกำหนดในการให้บริการของ Google ด้วย แอปขอสิทธิ์ drive.file, openid และ userinfo.email ตามที่อธิบายไว้ใน นโยบายความเป็นส่วนตัว

คุณเพิกถอนสิทธิ์ได้ทุกเมื่อที่ myaccount.google.com/permissions โครงการนี้ไม่มีส่วนเกี่ยวข้องกับ Google และไม่ได้รับการรับรองจาก Google

ไม่มีการรับประกันและข้อจำกัดความรับผิด

บริการนี้ให้บริการ "ตามสภาพที่เป็นอยู่" และ "ตามที่มีให้บริการ" โดยไม่มีการรับประกันใด ๆ ไม่ว่าจะเป็นเรื่องความพร้อมใช้งาน ความถูกต้อง ความคงอยู่ของไฟล์ หรือความเหมาะสมต่อวัตถุประสงค์เฉพาะ

ภายใต้ขอบเขตสูงสุดที่กฎหมายอนุญาต ผู้ดูแลไม่รับผิดชอบต่อการสูญหายของข้อมูล การไม่สามารถเข้าถึงบริการ หรือความเสียหายทางอ้อมหรือความเสียหายสืบเนื่อง โปรดเก็บสำเนาของข้อมูลสำคัญไว้ด้วยตนเอง เนื้อหาที่อยู่ในลิงก์และ subdomain เป็นความรับผิดชอบของเจ้าของ เราไม่ได้ตรวจสอบหรือรับรองเนื้อหาดังกล่าว

การยุติการใช้งาน
